# Evreki Wan Refanja - Portfolio Website

A modern, animated portfolio website featuring RGB neon gradients, glassmorphism effects, and smooth animations.

## 🚀 Features

- ⚡ Loading animation
- 🌈 RGB neon gradient theme
- 💎 Glassmorphism effects
- 🎬 Slide-from-left animations
- 🎯 Smooth scroll navigation
- 📱 Fully responsive design
- ✨ Hover effects on all interactive elements
- 🎨 Floating particle background
- 🖱️ Cursor trail effect

## 🛠️ Technologies Used

- HTML5
- CSS3 (with advanced animations)
- Vanilla JavaScript
- Google Fonts (Inter)

## 🌐 Deployment

This website can be deployed for free on:

### Option 1: Netlify (Recommended)
1. Create account at [netlify.com](https://netlify.com)
2. Drag and drop your project folder to Netlify Drop
3. Your site will be live in seconds!

### Option 2: Vercel
1. Create account at [vercel.com](https://vercel.com)
2. Import your project
3. Deploy with one click

### Option 3: GitHub Pages
1. Push code to GitHub repository
2. Go to Settings > Pages
3. Select main branch and save
